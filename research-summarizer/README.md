# Research Summarizer

A small command-line tool for research assistants: paste in a paper abstract, a
chunk of notes, or any block of text, and get back a concise set of key bullet
points, generated by the Claude API.

## Setup

1. **Install dependencies** (Python 3.9+):

   ```bash
   cd research-summarizer
   pip install -r requirements.txt
   ```

2. **Get an Anthropic API key** from the [Anthropic Console](https://console.anthropic.com/),
   then make it available to the script as an environment variable:

   ```bash
   export ANTHROPIC_API_KEY="your-api-key-here"
   ```

   (Add that line to your shell profile, e.g. `~/.bashrc` or `~/.zshrc`, so you
   don't have to re-export it every session.)

## Usage

Summarize text passed directly as an argument:

```bash
python summarize.py "Your paper abstract or notes go here..."
```

Summarize text from a file:

```bash
python summarize.py --file examples/sample_abstract.txt
```

Pipe text in from stdin:

```bash
cat examples/sample_abstract.txt | python summarize.py
```

### Example

```bash
$ python summarize.py --file examples/sample_abstract.txt
- LLMs frequently produce factually incorrect ("hallucinated") outputs, limiting
  their use in high-stakes domains.
- The authors propose a taxonomy splitting hallucinations into intrinsic
  (contradicts the source) and extrinsic (unverifiable against the source).
- They introduce a 5,000-example human-annotated benchmark covering
  summarization, QA, and open-ended generation.
- Evaluating eleven state-of-the-art models shows scale alone does not reduce
  hallucination rates.
- Retrieval augmentation and human-feedback fine-tuning each cut extrinsic
  hallucinations by over 30%, independently.
- Existing automatic metrics correlate poorly with human factuality judgments,
  motivating better evaluation protocols.
- The benchmark and annotation guidelines are released to support further
  research.
```

### Options

| Flag | Description |
|---|---|
| `text` (positional) | Text to summarize, passed directly as an argument |
| `--file`, `-f` | Path to a text file to summarize instead |
| `--model` | Claude model to use (default: `claude-opus-5`) |

If no text, `--file`, or piped stdin is provided, the script exits with a usage
message.

## How it works

`summarize.py` sends your text to the Claude API (`claude-opus-5` by default)
with a system prompt instructing it to return 3-7 concise markdown bullet
points capturing the key ideas, findings, and conclusions — no preamble, no
filler.
